# HiFi PRD

## Product goal

Booking sites help you find hotels. HiFi calls them.

## User flow

- Create a trip
- Search and rank hotels
- Start hotel calls
- Inspect structured offers
- Approve the best deal
- Simulate payment and confirmation

## Success criteria

- Top five hotels are surfaced
- CALL-E-style call tasks return structured results
- Offer comparisons are deterministic
- A user can complete payment and confirmation in a guided flow
